# OOP_CS

Учебный проект для детального разбора объектно-ориентированного программирования (ООП) на языке C#. Внутри реализованы классы для работы с точками на плоскости и математическими дробями, а также проверены механизмы инкапсуляции и перегрузки операторов.

## Как это устроено в теории
Проект показывает разницу в синтаксисе между C++ и C#:
* В C# модификаторы доступа (`private`, `public`) пишутся перед каждым отдельным полем или методом.
* Инкапсуляция реализуется не только через классические Get/Set методы, но и через специальные свойства класса (**Properties**), внутри которых в блоке `set` доступно ключевое слово `value`.
* Все перегруженные операторы объявляются как статические публичные методы (`public static`), принимающие один или два параметра. Операторы сравнения всегда перегружаются строго парами.

## Реализация в классах

### 1. Класс Point (Точка)
Небольшой класс, моделирующий точку с координатами `x` и `y`:
* Поля скрыты в `private` секции для защиты данных от некорректного внешнего вмешательства.
* В коде наглядно сопоставлены два подхода к инкапсуляции: стандартные методы (`GetX()`, `SetX()`) и синтаксические свойства `X` и `Y` с большой буквы. Свойства позволяют работать с объектом так же просто, как с обычной переменной, сохраняя безопасность данных.

### 2. Класс Fraction (Математическая дробь)
Более сложный класс, описывающий правильные, неправильные и смешанные дроби:
* **Разнообразие конструкторов:** В коде через директиву условной компиляции `#if CONSTRUCTORS_CHECK` проверяются разные типы создания объекта: конструктор по умолчанию (без параметров), конструктор целого числа, простой дроби (числитель и знаменатель) и смешанной дроби (целая часть, числитель, знаменатель).
* **Перегрузка арифметических операторов:** Перегружены операторы сложения, вычитания, умножения и деления (`/`, `*=`, `/=`). При выполнении операций они в обязательном порядке создают внутри себя через `new` и возвращают новый объект дроби.
* **Инкременты и декременты:** Перегружены операторы `D++` и `D--` для изменения дроби на единицу.
* **Операторы сравнения:** Попарно перегружены операторы равенства/неравенства (`==`, `!=`) и больше/меньше (`>`, `<`) для сравнения двух объектов дробей между собой как обычных чисел.

## Сборка и файлы конфигурации

1. Проект открывается в Visual Studio. Стандартный файл `AssemblyInfo.cs` содержит общие метаданные сборки (название, версию `1.0.0.0`) и GUID для регистрации проекта в системе.
2. В функции `main` создаются три дроби, проводятся расчеты (деление, умножение, инкремент) и вывод результатов в консоль. В самом конце идет проверка логических условий сравнения дробей с выводом результата `True` или `False`.
